# 问兰小程序 · 优惠券体系规范（C 档 · 三期）

> 真相源：`miniprogram/utils/requestRoutes.js`。**资金红线**：领券、兑换券/兑换码写入账户均为资金动作，未接通前 `toast 功能开发中`，仅展示券面。

## 页面清单

| 页面 | 路径建议 | 说明 |
| --- | --- | --- |
| 我的优惠券 | `pages/coupon/mine` | 可用/已用/过期 |
| 领券中心 | `pages/coupon/center` | 可领券列表 |
| 兑换券/兑换码 | `pages/coupon/exchange` | 输入码兑换 |

---

## 1. 我的优惠券 `pages/coupon/mine`

### Tab（等分，底部金色下划线）
`可使用 / 已使用 / 已过期`

### 券卡（横向票券造型）
- **左段**（深棕 `#1A1208` 底，宽 224rpx）：「减」小字 + 大额数字（3xl 白）+「满 ¥M 可用」。
- **中缝**：圆形缺口（`--color-cream` 圆点）+ 竖向虚线分隔。
- **右段**（白底）：券名（粗）+「有效期至 YYYY-MM-DD」+ 右下「去使用」金色链接（仅可用态）。
- 已用/过期态：整卡 `#F9F5F0` 底 + 60% 透明度，无操作按钮。

### 折扣类券
- discount 为满减显示数字；若为折扣券显示「N折」，金额位用 `price-text` 风格。

### 空态
「暂无{当前tab}优惠券」。

### 接口
`GET /coupons/mine?status=available|used|expired`

---

## 2. 领券中心 `pages/coupon/center`

- 顶部 banner（可选运营图）。
- 可领券列表：复用券卡，右段按钮为「领取 / 已领 / 已抢光」。
  - `领取`：金色实心 → **资金红线** → 接通前 toast，接通后 `POST /coupons/:id/receive`。
  - `已领`：描边「去使用」。
  - `已抢光`：置灰。
- 进度条（可选）：「已抢 X%」。
- 接口：`GET /coupons/center`、`POST /coupons/:id/receive`（红线）。

---

## 3. 兑换券/兑换码 `pages/coupon/exchange`

- 输入框（券码）+「兑换」按钮。
- 兑换结果反馈：成功 toast + 跳「我的优惠券」；失败提示原因。
- 我的券包入口 + 可兑换商品入口（如有积分兑换商品则跳积分中心）。
- **兑换写账户属资金红线** → 接通前 toast，接通后 `POST /coupons/exchange`。

---

## 与首批衔接
- 首页领券区「更多」→ 领券中心。
- 我的页「优惠券」→ 我的优惠券。
- 详情页 `points-coupon-bar` 的可用券领取统一走红线 toast。
