# 问兰小程序 · 颜色 & 排版规范

> 配套 `01-设计系统规范.md`。本文定义所有视觉令牌（color / typography / spacing / radius / shadow）。
> Codex 实现时**必须引用令牌**，禁止散落硬编码色值与字号。

## 1. 颜色令牌（Color Tokens）

全站主色严格控制在以下范围（米白 + 金 + 深棕 + 暖灰 + 极少量功能色）。

### 1.1 品牌与中性色

| 令牌名 | 色值 | 用途 |
| --- | --- | --- |
| `--color-bg` | `#FAF7F4` | 页面背景（米白） |
| `--color-surface` | `#FFFFFF` | 卡片/弹层背景 |
| `--color-surface-warm` | `#F5EFE8` | 图片占位、次级区块、搜索框底 |
| `--color-primary` | `#1A1208` | 主文字、主按钮底色（深棕，替代黑） |
| `--color-primary-light` | `#3D2B1A` | 次级文字、图标 |
| `--color-muted` | `#8C7B6B` | 辅助文字、占位符、未激活态 |
| `--color-border` | `#E8DDD0` | 主分割线、卡片描边 |
| `--color-border-light` | `#F0E8DC` | 浅分割线 |

### 1.2 金色（强调色，仅点缀）

| 令牌名 | 色值 | 用途 |
| --- | --- | --- |
| `--color-gold` | `#B8973A` | 价格强调、激活态、徽标、HOT 标签 |
| `--color-gold-light` | `#D4AF5A` | 金色高光、渐变亮端 |
| `--color-gold-pale` | `#F0E6C8` | 金色浅底（标签底、头像底） |

### 1.3 功能色（仅状态提示用，克制使用）

| 令牌名 | 色值 | 用途 |
| --- | --- | --- |
| `--color-success` | `#4A7C59` | 成功（已加入购物车等） |
| `--color-danger` | `#C2453A` | 删除、错误、库存告罄 |
| `--color-on-primary` | `#FFFFFF` | 深色底上的文字（白） |

> 颜色总数控制：品牌米白系 + 金色系 + 深棕文字系 + 2 个功能色，符合「不超过 5 主色」原则。
> **禁止**：纯黑 `#000`、紫色、与品牌无关的高饱和色。

## 2. 排版（Typography）

### 2.1 字体族
```
font-family: -apple-system, "PingFang SC", "Helvetica Neue", Arial, sans-serif;
```
- 小程序使用系统字体，无需下载字体文件。
- 不使用衬线体（Web 版的 Georgia 在小程序中省略）。
- 数字（价格、倒计时、库存）使用 `font-variant-numeric: tabular-nums` 等宽对齐。

### 2.2 字号 / 字重 / 行高阶梯

| 令牌名 | 字号(rpx) | 字重 | 行高 | 典型用途 |
| --- | --- | --- | --- | --- |
| `--fs-display` | 40 | 700 | 1.3 | 页面大标题（我的页用户名、价格大数） |
| `--fs-title` | 36 | 700 | 1.3 | 卡片/区块主标题 |
| `--fs-heading` | 32 | 700 | 1.35 | section 标题「热门推荐」 |
| `--fs-body-lg` | 30 | 600 | 1.4 | 商品名、重点正文 |
| `--fs-body` | 28 | 400 | 1.5 | 常规正文 |
| `--fs-sub` | 26 | 400 | 1.5 | 副标题、辅助说明 |
| `--fs-caption` | 24 | 400 | 1.4 | 次级说明、标签文字 |
| `--fs-mini` | 20 | 500 | 1.3 | 角标、徽标、超小字（NEW/HOT） |

> 字重仅用 400 / 500 / 600 / 700 四档。正文行高 1.5，标题 1.3。
> 正文最小字号不低于 24rpx（≈12px）。

### 2.3 字间距
- 英文/品牌标语（如 `WENLAN BEAUTY`）：`letter-spacing: 4rpx`，大写。
- 中文正文：默认 0。
- 标签/徽标：`letter-spacing: 2rpx`。

## 3. 间距系统（Spacing）

基于 4 的倍数（rpx）：

| 令牌名 | 值(rpx) | 典型用途 |
| --- | --- | --- |
| `--space-xs` | 8 | 图标与文字间隙 |
| `--space-sm` | 16 | 元素内小间距 |
| `--space-md` | 24 | **页面左右内边距（统一）**、卡片内边距 |
| `--space-lg` | 32 | 区块之间间距 |
| `--space-xl` | 40 | 大区块分隔 |
| `--space-2xl` | 56 | 页面顶部/底部留白 |

规则：
- 页面内容容器左右内边距统一 `--space-md`（24rpx）。
- 区块（section）之间垂直间距 `--space-lg`（32rpx）。
- **同一元素禁止同时用 margin 和 gap**；列表优先用 flex + gap。
- 卡片内边距 `--space-md`。

## 4. 圆角与阴影

### 4.1 圆角（Radius）

| 令牌名 | 值(rpx) | 用途 |
| --- | --- | --- |
| `--radius-sm` | 8 | 小标签、图片小卡 |
| `--radius` | 24 | 卡片、按钮、输入框（默认） |
| `--radius-lg` | 40 | 大卡片、底部弹层顶部 |
| `--radius-full` | 9999 | 胶囊按钮、徽标、头像 |

### 4.2 阴影（Shadow，仅一层极淡）

| 令牌名 | 值 | 用途 |
| --- | --- | --- |
| `--shadow-card` | `0 2rpx 16rpx rgba(26,18,8,0.05)` | 卡片默认浮起 |
| `--shadow-float` | `0 8rpx 28rpx rgba(184,151,58,0.35)` | 金色悬浮按钮（仅 AI 按钮） |

> 不滥用阴影；列表卡片仅 `--shadow-card`，多数区块用底色区分层级而非阴影。

## 5. WXSS 令牌落地方案（重要）

微信小程序自定义组件有**样式隔离**，页面级 CSS 变量无法自动穿透进组件。推荐双轨方案：

### 5.1 页面层：CSS 变量
在 `app.wxss` 顶部定义 `page` 级变量，页面 WXSS 可直接用 `var(...)`：

```css
/* app.wxss */
page {
  --color-bg: #FAF7F4;
  --color-surface: #FFFFFF;
  --color-surface-warm: #F5EFE8;
  --color-primary: #1A1208;
  --color-primary-light: #3D2B1A;
  --color-muted: #8C7B6B;
  --color-border: #E8DDD0;
  --color-border-light: #F0E8DC;
  --color-gold: #B8973A;
  --color-gold-light: #D4AF5A;
  --color-gold-pale: #F0E6C8;
  --color-success: #4A7C59;
  --color-danger: #C2453A;

  --radius-sm: 8rpx;
  --radius: 24rpx;
  --radius-lg: 40rpx;

  --shadow-card: 0 2rpx 16rpx rgba(26,18,8,0.05);

  background-color: var(--color-bg);
  color: var(--color-primary);
  font-family: -apple-system, "PingFang SC", "Helvetica Neue", Arial, sans-serif;
  font-size: 28rpx;
  line-height: 1.5;
}
```

### 5.2 组件层：开启样式穿透
自定义组件中若要复用 page 变量，在组件 `.js` 的 `options` 中开启：

```js
Component({
  options: {
    addGlobalClass: true,        // 允许 app.wxss 全局类生效
    styleIsolation: 'apply-shared' // 允许页面变量穿透
  }
})
```
> 用 `apply-shared` 后，组件即可使用 `var(--color-gold)` 等 page 变量。

### 5.3 通用原子类（`styles/common.wxss`，被 `app.wxss` `@import`）
```css
.card {
  background: var(--color-surface);
  border-radius: var(--radius);
  box-shadow: var(--shadow-card);
}
.gold-divider {
  height: 1rpx;
  background: linear-gradient(90deg, transparent, var(--color-gold), transparent);
}
.price {
  color: var(--color-primary);
  font-weight: 700;
  font-variant-numeric: tabular-nums;
}
.price__symbol { font-size: 24rpx; }
.text-muted { color: var(--color-muted); }
.hairline { border-bottom: 1rpx solid var(--color-border-light); }
.ellipsis-1 { overflow: hidden; white-space: nowrap; text-overflow: ellipsis; }
.ellipsis-2 {
  display: -webkit-box; -webkit-box-orient: vertical;
  -webkit-line-clamp: 2; overflow: hidden;
}
```

## 6. 价格展示规范（统一）

价格是电商核心元素，统一格式：
- 货币符号 `¥` 字号比数字小一档（`--fs-caption`），数字用主字号 + 700。
- 现价用 `--color-primary`；划线原价用 `--color-muted` + `text-decoration: line-through` + 小一档字号。
- 大额价格（详情页）数字可用 `--fs-display`。
- 折扣角标：金色底 `--color-gold` + 白字 `--fs-mini`，如 `-30%`。

示例结构：
```html
<view class="price">
  <text class="price__symbol">¥</text>
  <text class="price__num">598</text>
  <text class="price__origin">¥780</text>
</view>
```
