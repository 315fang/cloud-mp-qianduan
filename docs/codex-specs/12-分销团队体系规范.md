# 问兰小程序 · 分销/团队/钱包体系规范（C 档 · 五期）

> 真相源：`miniprogram/utils/requestRoutes.js`。
> **资金红线（最严格）**：本模块几乎全部涉及佣金、货款、提现、资金账户。所有金额**只读展示**，**提现申请、确认提交、划拨等写操作一律 `toast 功能开发中`**，接口接通由后端财务校验。
> **权限**：所有页面仅对具备分销/店长身份的用户可见，入口在「我的」角色区按 `GET /user/roles` 控制。

## 页面清单

| 页面 | 路径建议 | 说明 |
| --- | --- | --- |
| 分销工作台 | `pages/distributor/index` | KPI、快捷、邀请码、排行、佣金记录 |
| 我的团队 | `pages/distributor/team` | 成员列表、筛选、搜索 |
| 我的钱包 | `pages/distributor/wallet` | 余额、提现弹窗、流水 |
| 佣金明细 | `pages/distributor/commission` | 多状态、可展开详情 |
| 邀请好友 | `pages/distributor/invite` | 邀请码、分享、奖励、记录 |
| 申请经销 | `pages/distributor/apply` | 入驻表单 |
| 分销规则 | `pages/distributor/rules` | 规则说明 |
| 提现历史/进货/库存日志 | `pages/distributor/*` | 列表类，沿用同款卡片规范 |

## 通用视觉基调
- 顶部导航与头部区域用**深棕 `#1A1208` 底 + 白字 + 金色高亮**，营造「工作台」专业感。
- 金额配色语义：收入/已结算 **绿 `#2D8C5E`**，待结算/冻结 **金 `#B8973A`**，支出/驳回 **赭 `#B85A2A`**。
- 状态标签统一胶囊：绿底 `#E8F5EE` / 金底 `#FBF5E6` / 赭底 `#FBF0E8` / 灰底 `#F5EFE8`。

## 1. 分销工作台 `pages/distributor/index`

1. **顶部导航**（深棕）：返回 + 「分销工作台」+ 通知铃（带红点）。
2. **等级横幅**（深棕）：昵称 + 等级胶囊 + 经销商编号；右侧本月业绩/目标；底部金色渐变进度条 +「距 L3 还差 ¥X」。
3. **KPI 网格**（2×2，上移盖住横幅）：本月佣金 / 钱包余额 / 累计佣金 / 团队人数，各卡不同语义色副文案。
4. **快捷操作**（4 列宫格）：佣金明细 / 我的钱包 / 我的团队 / 推广素材 / 选品下单 / 佣金日志 / 分销规则 / 申请经销。
5. **邀请码卡**（深棕）：专属邀请码大字 + 复制按钮（`wx.setClipboardData`）。
6. **团队排行（本月）**：排名 + 头像首字 + 姓名 + 销售额 + 佣金 + 等级标签，前 3 名金色。
7. **近期佣金记录**：商品 + 订单号/时间 + `+佣金` + 状态标签。
- 工作台是 tabBar 页之一（带 BottomNav）或从「我的」进入，二选一由路由表决定。
- 接口：`GET /distributor/dashboard`（聚合）。

---

## 2. 我的团队 `pages/distributor/team`

1. **头部**（深棕）：返回 +「我的团队」+ 右上邀请按钮（金色圆，跳 invite）。
2. **团队数据卡**（3 列半透明）：总人数 / 本月业绩 / 本月佣金。
3. **搜索栏**：圆角输入框，按姓名筛选。
4. **分类 Tab**（胶囊横滑）：全部 / L2 / L1 / 不活跃，带计数。
5. **成员列表**：头像首字（按等级配色）+ 姓名 + 等级标签 + 状态标签（活跃绿/新人蓝/不活跃灰）+ 脱敏手机/加入月份 + 本月销售/佣金 + 右箭头进成员详情。
- 空态：Users 图标 +「暂无成员」。
- 接口：`GET /distributor/team?level=&status=&keyword=`、`GET /distributor/team/:id`（详情）。

---

## 3. 我的钱包 `pages/distributor/wallet`

1. **顶部导航**（深棕）：返回 +「我的钱包」+ 余额显隐眼睛切换。
2. **余额区**（深棕）：「可提现余额」大字（隐藏时 `••••••`）+ 冻结中 + 累计提现。
3. **操作按钮**（上移）：金色「申请提现」+ 白色「佣金明细」。
4. **说明卡**（`#FBF5E6`）：提现时间、限额、手续费、到账时效说明。
5. **账单流水**：收入绿色下箭头 / 支出赭色上箭头 + 标题 + 时间 + 状态标签 + 带符号金额。
6. **提现弹窗**（底部抽屉，多步）：
   - `input`：金额输入（带「全部」）+ 提现方式选择（微信零钱 / 银行卡，单选卡）。
   - `confirm`：金额 / 手续费 / 实际到账 / 方式 / 时效明细 + 修改/确认提交。
   - `success`：对勾 +「提现申请已提交」。
- **整个提现链路属资金红线** → 弹窗 UI 可完整实现，但「确认提交」接通前 `toast 功能开发中`；接通后 `POST /distributor/withdraw`，**金额与到账由后端财务裁决**。
- 接口：`GET /distributor/wallet`、`GET /distributor/wallet/ledger`、`POST /distributor/withdraw`（红线）。

---

## 4. 佣金明细 `pages/distributor/commission`

1. **顶部导航**（深棕）+ **统计区**（已结算/冻结中/待审批三列）+ 解冻规则说明。
2. **状态 Tab**（吸顶横滑）：全部 / 冻结中 / 待审批 / 已结算 / 已驳回，带计数。
3. **佣金卡（可展开）**：状态图标 + 商品 + 买家/层级/时间 + `+¥佣金` + 状态标签；
   - 展开：关联订单号 / 订单金额 / 佣金比例 / 结算时间；冻结显示解冻说明，驳回显示原因。
- 接口：`GET /distributor/commission?status=`。
- 全为只读，无资金写操作。

---

## 5. 邀请好友 `pages/distributor/invite`

1. **头部**（深棕，带装饰圆）：REFERRAL PROGRAM + 标题 + 副文案 + 3 列统计（已邀请/待发奖励/累计收益）。
2. **邀请码卡**：大字邀请码 + 复制；3 列分享方式：
   - 分享给好友：`<button open-type="share">`（小程序原生转发，**替代** Web 的自定义按钮）。
   - 我的二维码：生成小程序码海报（`canvas` + `wx.saveImageToPhotosAlbum`）。
   - 复制链接：小程序内改为复制邀请码或页面路径。
3. **邀请奖励规则**：好友注册→¥10、首单→¥30、升级 L2→¥100，图标 + 触发 + 奖励 + 说明。
4. **邀请记录**：头像 + 姓名 + 完成步骤/日期 + 奖励 + 已发放标签。
- **奖励金额只读**；发放由后端触发。
- 接口：`GET /distributor/invite/summary`、`GET /distributor/invite/records`。

---

## 6. 申请经销 `pages/distributor/apply`
- 入驻表单：姓名 / 手机 / 微信 / 意向等级 / 备注 + 协议勾选 + 提交。
- 说明「提交后由问兰商务团队 1 个工作日内审核」。
- 接口：`POST /distributor/apply`（非资金，可接通）。

## 7. 分销规则 `pages/distributor/rules`
- 纯内容页：三层分销体系说明、佣金比例、结算规则、合规声明。深棕说明卡 + 正文。

## 8. 列表类页面（提现历史/进货记录/库存日志）
- 沿用「状态 Tab + 卡片列表 + 状态标签」统一范式，金额只读。
- 接口：`GET /distributor/withdraw-history`、`/restock`、`/stock-logs`。

---

## 实现提示
- 复用组件：`kpi-card`、`commission-card`、`ledger-item`、`member-item`、`order-status-tag`、`price-text`。
- 分享统一用小程序原生 `open-type="share"` + 海报 canvas，不照搬 Web 自定义分享。
- 严守资金红线：余额、佣金、奖励全只读；提现/划拨等写操作 toast，金额由后端裁决。
