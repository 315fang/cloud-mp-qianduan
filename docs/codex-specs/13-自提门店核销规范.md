# 问兰小程序 · 自提/门店/核销规范（C 档 · 五期）

> 真相源：`miniprogram/utils/requestRoutes.js`。**资金红线**：核销提交、库存采购等写操作止于接口边界，未接通前 `toast 功能开发中`。门店浏览、导航、电话为只读，可接通。
> **权限**：核销页、门店工作台仅对店长/门店身份可见（`GET /user/roles`）。

## 页面清单

| 页面 | 路径建议 | 说明 | 可见角色 |
| --- | --- | --- | --- |
| 自提门店选择 | `pages/pickup/stations` | 地图 + 门店列表 | 全部 |
| 核销台 | `pages/pickup/verify` | 扫码/输码核销 | 店长/门店 |
| 待核销订单 | `pages/pickup/pending` | 待提货列表 | 店长/门店 |

---

## 1. 自提门店选择 `pages/pickup/stations`

整页底色 `#F5EFE8`，顶栏白底。

### 区块
1. **顶栏**：返回 +「选择自提门店」。
2. **地图区**（圆角卡，高 ~352rpx）：
   - Web 版是占位灰块；**小程序必须使用原生 `<map>` 组件**，渲染门店 marker + 当前定位（`wx.getLocation`）。
3. **门店列表卡**（可单选，选中金色 2rpx 描边 ring）：
   - 门店名 + 「暂无库存」红标签（库存 0 时）。
   - 地址（muted）。
   - 营业时间（Clock）+ 电话（Phone）。
   - 右侧：距离（金色）+ Navigation 图标（点击 `wx.openLocation` 导航）。
   - 有库存时底部绿字「库存充足，可自提 N 件」。
4. **底部固定栏**：「确认选择门店」，未选置灰。

### 接口
- `GET /pickup/stations?lat=&lng=`（按距离排序）。
- 选择后回填到结算页（`?select=1` 模式）。

---

## 2. 核销台 `pages/pickup/verify`（店长/门店）

### 区块
1. **顶栏**：返回 +「核销台」。
2. **扫码区**（主操作）：大号「扫码核销」按钮 → `wx.scanCode` 扫提货码。
3. **手动输入区**：核销码输入框 + 「核销」按钮（扫码失败的兜底）。
4. **核销结果反馈**：
   - 成功：绿色对勾 + 订单/商品信息 + 「核销成功」。
   - 失败：红色 + 原因（码无效/已核销/不属本店）。
5. **今日核销记录**：列表（订单号 + 商品 + 时间）。

### 红线
- 扫码/输码可做，**核销提交 `POST /pickup/verify` 属资金履约红线** → 接通前 toast；接通后由后端校验并返回结果。

### 接口
- `POST /pickup/verify`（红线）、`GET /pickup/verify/records?date=today`。

---

## 3. 待核销订单 `pages/pickup/pending`（店长/门店）

- 顶栏 +「待核销订单」。
- 列表卡：买家脱敏信息 + 商品 + 提货码（部分隐藏）+ 下单时间 + 「去核销」按钮（跳核销台并带单号）。
- 状态筛选：待提货 / 已核销。
- 空态：「暂无待核销订单」。
- 接口：`GET /pickup/pending`、`GET /pickup/orders?status=`。

---

## 实现提示
- 地图必须用小程序原生 `<map>` + `wx.getLocation`/`wx.openLocation`，不要照搬 Web 占位块。
- 扫码用 `wx.scanCode`；电话用 `wx.makePhoneCall`。
- 门店卡可抽 `station-card` 组件。
- 严守红线：核销提交由后端裁决，前端只发起。
