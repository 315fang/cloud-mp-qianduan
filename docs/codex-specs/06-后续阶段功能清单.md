# 问兰小程序 · 后续阶段功能清单（C 档留档）

> 本文不在首批实现范围内，仅作**完整留档**，确保 design 缺口不丢失。
> 这些模块多涉及支付、退款、佣金、资金账户、活动履约，需在首批 5 页稳定后**单独立项设计**。
> 首批 5 页内若出现这些模块的入口，仅保留 UI 占位，点击 `toast 功能开发中`。

## 分期规划建议

| 阶段 | 模块 | 依赖 |
| --- | --- | --- |
| 二期 | 订单体系、地址管理（增删改） | 支付能力 |
| 三期 | 售后/退款、优惠券中心、积分中心 | 资金账户、退款流 |
| 四期 | 活动体系（拼团/砍价/限时专场/抽奖） | 活动履约引擎 |
| 五期 | 分销/团队、钱包、自提/门店/核销 | 佣金结算、门店系统 |

---

## 1. 订单体系
- 订单列表（含 **待成团**、**自提待核销** 等扩展状态 Tab）。
- 订单卡：**支付方式差异态**（微信支付 / 货款余额 / 兑换券 / 0 元积分兑换标签）、**活动订单条**。
- 订单详情、物流跟踪、确认收货、评价。
- 自提订单链路：核销码卡片、提货页、查看门店。

## 2. 售后 / 退款
- 退款申请页：原因选择器、上传凭证、选择商品、说明。
- 按订单发起售后的商品选择页。
- 售后详情：商家寄回地址卡 + 复制、回寄物流单号录入、取消申请。

## 3. 地址体系
- 地址列表页：默认标识、编辑/删除、设默认。
- 地址编辑页：姓名/手机/地区选择/详细地址、**导入微信地址**。

## 4. 积分体系
- 积分中心页：余额、签到、获取记录、规则说明、任务。
- 积分抽奖页：抽奖主视觉、奖池卡、中奖弹窗、中奖记录、领奖流。

## 5. 优惠券体系
- 领券中心页：可领 / 已领 / 去使用 / 不可用说明。
- 兑换券 / 兑换码页：兑换输入、券包状态、兑换商品入口。

## 6. 分销 / 团队体系
- 团队列表（一级/二级）、成员详情、上下级关系、划拨。
- 佣金明细 / 货款明细 / 基金池：明细列表、筛选、状态标签。
- 定向邀约 / 推广合伙人：邀约列表、详情、发起表单。
- 邀请海报页：海报预览、保存相册、复制 ID。

## 7. 自提 / 门店体系
- 自提站点地图页：地图、门店卡、距离、导航、电话、复制地址。
- 我的门店 / 站点工作台：库存卡、采购申请、核销记录。
- 核销页 / 待核销订单页：待核销列表、扫码、输入核销码、结果反馈。

## 8. 活动体系
- 活动总页：活动分区、活动卡、状态标签。
- 拼团专区：拼团商品、我的拼团、邀请参团。
- 砍价专区：砍价列表、进度条、帮砍记录。
- 限时专场 / 随心选：倒计时、活动库存、活动价、参与规则。
- 品牌资讯：资讯列表 + 详情正文 + 封面大图。
