# 问兰小程序 · 首批页面设计规范

> 配套 `01~03` 文档。本文逐页给出布局结构、模块顺序、数据来源、交互与状态。
> 接口字段映射详见 `05-API接口对接指南.md`。
> **排除范围**（订单/售后/钱包/分销/支付）相关入口：保留 UI，点击仅 `wx.showToast({title:'功能开发中'})`。

## TabBar 全局配置

`app.json` 的 `tabBar`（4 个 tab + 中间「问小兰」为页面内悬浮，不放进原生 tabBar）：

| 顺序 | 文字 | 页面 | 图标 |
| --- | --- | --- | --- |
| 1 | 首页 | `pages/index/index` | home |
| 2 | 分类 | `pages/category/category` | category |
| 3 | 购物车 | `pages/cart/cart` | cart（带角标） |
| 4 | 我的 | `pages/user/user` | user |

- 选中色 `#B8973A`，未选中 `#8C7B6B`，背景 `#FFFFFF`，上边框 `#E8DDD0`。
- 购物车角标：用 `wx.setTabBarBadge` 显示购物车件数（数据来自 `GET /cart`）。

# 页面 1 · 首页 `pages/index/index`

### 模块顺序（从上到下）
1. **顶部公告条**：深棕底 `--color-primary`，`NEW` 金色徽标 + 滚动文案（来自 `GET /banners` 或 `GET /page-content/home` 的公告字段，无则隐藏）。
2. **品牌头 + 工具栏**：左「问兰护肤 / WENLAN BEAUTY」，右「消息铃铛（红点）+ 搜索」。铃铛跳转本批不实现 → toast；搜索点击进入分类页搜索态。
3. **搜索框**（胶囊，底 `--color-surface-warm`）：点击跳 `pages/category/category?focus=1`。
4. **Banner 轮播**：`swiper` 自动轮播，圆角 `--radius`，来自 `GET /banners`。点击按 banner 的跳转类型处理（商品→详情；活动→本批 toast）。
5. **限时特惠**（横向滚动）：`section-header` 标题「限时特惠」+ 倒计时；横滑商品卡（含进度条与「仅剩 X 件」）。商品来自 `GET /products?sort=...` 或活动接口，本批可用 `GET /products` 前若干条。倒计时本地 `setInterval`。
6. **分类金刚区**（可选）：`GET /categories` 横向图标入口，点击跳分类页对应分类。
7. **热门推荐**：`section-header`「热门推荐」+「查看全部」；2 列网格 `product-card`（grid）。数据 `GET /products`（取 isHot/isNew）。
8. **底部品牌信息**：金色分割线 + 「WENLAN BEAUTY · 问兰」标语。

### 数据与生命周期
- `onLoad`：并行请求 banners、categories、products；先显示 `skeleton`。
- `onPullDownRefresh`：重新拉取全部，完成 `wx.stopPullDownRefresh`。
- 倒计时在 `onShow` 启动、`onHide` 清除，防止内存泄漏。

### 状态
- 加载：骨架屏（banner 块 + 2 列卡片骨架）。
- 错误：toast +「点击重试」。
- 空：极少出现；若 products 为空，热门区显示 `empty-state`。

# 页面 2 · 分类 / 商品列表 `pages/category/category`

左侧分类竖向导航 + 右侧商品列表的经典布局，并支持搜索。

### 布局
```
┌──────────────────────────┐
│ 搜索栏（含返回，可聚焦）        │  ← focus=1 时自动聚焦
├──────┬───────────────────┤
│ 分类 │  排序栏（综合/销量/价格）   │
│ 侧栏 ├───────────────────┤
│(左) │  商品列表（list 卡 / 2列网格）│
│      │  上拉加载更多              │
└──────┴───────────────────┘
```

### 模块
1. **搜索栏**：顶部，输入跳 `GET /products/search`。`focus=1` 参数时自动 `focus`。
2. **左侧分类栏**：宽 180rpx，竖排 `GET /categories`。选中项左侧金色竖条 + 白底 + 文字加粗；未选 `--color-surface-warm`。
3. **排序栏**：综合 / 销量 / 价格（价格点击切换升降序箭头）。激活态金色。
4. **商品列表**：默认 `product-card` list 横卡；可提供网格切换。数据 `GET /products?category=&sort=&page=`。
5. **分页**：`onReachBottom` 加载下一页，底部「加载中 / 没有更多了」。

### 交互
- 切换分类：重置 page=1，滚动回顶。
- 加购：点 list 卡加购按钮 → 打开 `sku-sheet` → confirm 调 `POST /cart`，成功后更新购物车 tabBar 角标。

### 状态
- 加载：右侧列表骨架（list 类型）。
- 空：搜索/筛选无结果 → `empty-state`「没有找到相关商品」。
- 错误：toast + 重试。

# 页面 3 · 商品详情 `pages/product/detail`

进入参数：`?id=商品ID`。数据主源 `GET /products/:id`，评价 `GET /products/:id/reviews`。

### 模块顺序
1. **自定义导航栏** `nav-bar`：沉浸式，`onPageScroll` 控制 `bgOpacity`。
2. **主图区**：`swiper` 商品图集，1:1，底 `--color-surface-warm`。右下角页码 `1/5`。
3. **价格区**（白卡）：大号 `price-text`（lg）现价 + 划线原价 + 折扣 `tag-label`；右侧收藏 ♥（`GET /user/favorites/status` 判断，点 `POST/DELETE /user/favorites`）。
4. **标题区**：商品名（`--fs-title`）+ 副标题 + 标签组（`tag-label`）+ 销量/评分。
5. **规格摘要行**：显示「已选 默认规格」，点击打开 `sku-sheet`。右箭头。
6. **服务承诺行**：正品保障 / 七天无理由（仅展示）/ 顺丰发货 等图标文案（静态或来自 config）。
7. **商品详情**：`description` 文本 + 详情图（`rich-text` 或图片流）。规格参数表（`product.specs`）。
8. **用户评价**：`section-header`「用户评价」+ 评分；列出 2~3 条 `GET /products/:id/reviews`，更多本批可 toast 或留空。
9. **底部操作栏**（fixed，安全区）：
   - 左：客服图标（toast 开发中）、收藏、购物车图标（跳购物车）。
   - 右：**加入购物车**（描边/次按钮）+ **立即购买**（主按钮）。
   - 「加入购物车」→ `sku-sheet` mode=cart → `POST /cart`。
   - 「立即购买」→ 进入下单/支付，属**排除范围** → 点击 `toast 功能开发中`。

### 状态
- 加载：detail 骨架（大图块 + 文字条 + 底栏）。
- 错误/不存在：整页 `empty-state`「商品不存在或已下架」+ 返回按钮。

# 页面 4 · 购物车 `pages/cart/cart`

数据源 `GET /cart`。本批实现「展示 + 选择 + 改数量 + 删除」，**结算按钮属排除范围**（进入下单/支付）→ toast 开发中。

### 模块
1. **导航标题**：「购物车」+ 右上「管理」（进入编辑/批量删除态）。
2. **失效/空提示**：无商品 → `empty-state`「购物车还是空的」+「去逛逛」跳首页。
3. **店铺/商品列表**：每项 = 左多选框 + 商品图(160rpx) + 名称/规格 + `price-text` + `quantity-stepper`。
   - 改数量：`PUT /cart/:id`。
   - 左滑或编辑态删除：`DELETE /cart/:id`，确认弹窗。
   - 单选/全选用本地 + `POST /cart/check`（同步选中态，可选）。
4. **底部结算栏**（fixed，安全区）：
   - 左：全选框 + 「合计 ¥xxx」（仅累加选中项，前端计算展示）。
   - 右：**去结算（N）** 按钮 → **排除范围** → `toast 功能开发中`（不跳转、不调下单接口）。
   - 编辑态时右侧按钮变「删除选中」。

### 交互与状态
- 进入与 `onShow` 都刷新购物车（从详情加购返回需更新）。
- 数量变更后实时更新合计与 tabBar 角标。
- 加载：list 骨架。错误：toast。

# 页面 5 · 我的 `pages/user/user`

数据源：`GET /user/profile`、`GET /user/account-snapshot`、`GET /user/stats`。
**严格按角色/场景分区**（沿用 Web 版重构后的信息架构）。

### 模块顺序
1. **用户信息卡**（深棕渐变卡 `--color-primary`）：
   - 头像（无则用金色圆底「问」字占位）+ 昵称（`GET /user/profile`）+ 会员等级徽标（`GET /user/member-tier-meta`）。
   - 未登录态：显示「点击登录」，点击触发 `wx.login` → `POST /login` 流程。
   - 资产四格：积分 / 优惠券 / 收藏 / 余额（来自 `account-snapshot`）。**余额/钱包项点击属排除范围 → toast**；积分、优惠券、收藏可跳对应轻页面或本批 toast。
2. **我的订单**（白卡）：标题 + 「全部订单」。5 宫格状态入口（待付款/待发货/待收货/待评价/退款售后）带数字角标（`GET /orders/counts`）。
   - **本批：订单全属排除范围** → 整块保留 UI、显示角标数字，点击任意项 `toast 功能开发中`。
3. **浏览足迹**（横滑）：紧跟订单。本批可用收藏 `GET /user/favorites` 或本地足迹；无数据则隐藏整块。
4. **买家工具**（白卡，4 宫格）：地址管理 / 优惠券 / 我的收藏 / 客服中心。
   - 地址管理可实现（`GET /addresses`，本批若只读则展示列表；增删改可后续）。其余可跳轻页面或 toast。
5. **分销工作台**（白卡，独立分区，与买家工具视觉隔离）：钱包 / 推广素材 / 店长工作台 / 自提核销 / 团队中心。
   - **整块属排除范围** → 保留入口 UI，点击全部 `toast 功能开发中`，不调用 distribution/wallet/agent 任何接口。
6. **设置**（独立列表行）：跳设置页或 toast。

### 状态
- 未登录：信息卡显示登录引导，下方功能区正常展示但点击需登录的项先引导登录。
- 加载：信息卡 + 卡片骨架。
- 错误：toast，关键信息（昵称/资产）失败用占位「--」。
