# 问兰小程序 · 首批页面设计规范

> 配套 `01~03` 文档。本文逐页给出布局结构、模块顺序、数据来源、交互与状态。
> 接口字段映射详见 `05-API接口对接指南.md`。C 档后续功能见 `06-后续阶段功能清单.md`。

## 范围与边界（务必先读）

本批 = 5 个页面：首页 / 分类 / 详情 / 购物车 / 我的。

三类功能的处理方式：

| 档 | 含义 | Codex 实现方式 |
| --- | --- | --- |
| **A 档** | 属于 5 页、不涉及资金 | **完整实现**（UI + 数据 + 交互 + 四态） |
| **B 档** | 在 5 页内露头、涉及活动/资金 | **完整设计 UI 与状态**；但触发资金的最终动作（支付、扣积分兑换、领券写账户、开团付款）止于接口边界 → `toast 功能开发中`，**不调用**资金/下单接口 |
| **C 档** | 完全在 5 页外（订单/售后/钱包/分销工作台/活动专区等独立页） | 不在本批，见 `06`。5 页内若有入口仅保留 UI + toast |

**资金红线**：以下接口本批一律零调用——下单/支付、退款、佣金、货款余额、积分扣减提交、拼团开团付款、核销。涉及它们的按钮点击统一 `wx.showToast({title:'功能开发中'})`。

# 页面 1 · 首页 `pages/index/index`

### 模块顺序（从上到下）
1. **顶部公告条**：深棕底 `--color-primary`，`NEW` 金色徽标 + 滚动文案（来自 `GET /banners` 或 `GET /page-content/home` 公告字段，无则隐藏）。
2. **品牌头 + 工具栏**：左「问兰护肤 / WENLAN BEAUTY」，右「消息铃铛（红点）+ 搜索」。铃铛本批 → toast；搜索进入分类页搜索态。
3. **搜索框**（胶囊，底 `--color-surface-warm`）：点击跳 `pages/category/category?focus=1`。
4. **签到 / 积分触达条**【A 档】：品牌头下方或资产位的细条。
   - 展示积分余额（`GET /user/points/summary`）+「签到」按钮。
   - 未签到：金色「签到」按钮；点击 `POST /user/points/sign-in` → 成功后弹积分奖励轻提示（`+N 积分`）并置灰为「已签到」。
   - 未登录：按钮显示「登录领积分」，点击走登录流。
   - 接口缺失或失败：整条隐藏，不报错。
5. **Banner 轮播**：`swiper` 自动轮播，圆角 `--radius`，来自 `GET /banners`。点击按 banner 跳转类型处理（商品→详情；活动→本批 toast）。
6. **优惠券领取区**【A 档】：`section-header`「领券中心」+「更多」。
   - 横滑 `coupon-card`：左金额/折扣，右名称 + 门槛 + 领取状态。数据 `GET /coupons/home`（或 `GET /coupons?scene=home`）。
   - 状态：可领（金色「领取」）/ 已领（描边「去使用」跳分类）/ 已抢光（置灰「已抢光」）。
   - 「领取」点击 `POST /coupons/:id/receive` —— **此为领券写账户，属资金红线** → 本批改为 `toast 功能开发中`，不调用领取接口（仅展示券面与状态）。
   - 无券：整区隐藏。
7. **限时特惠**（横向滚动）【B 档 UI】：`section-header`「限时特惠」+ 倒计时；横滑商品卡含进度条与「仅剩 X 件」。
   - 数据来自活动接口或 `GET /products` 前若干条；倒计时本地 `setInterval`。
   - 卡片点击进入详情页并带 `?mode=flash`（详情页据此切到限时专享态，见页面 3）。
8. **分类金刚区**（可选）：`GET /categories` 横向图标入口，点击跳分类页对应分类。
9. **品牌专区 / 品牌内容流**【A 档】：
   - **品牌主视觉卡**：大图 + 品牌名 + 一句话标语（`GET /brands/featured` 或 `GET /page-content/home` 的 brandZone）。
   - **品牌卡组**：横滑品牌卡（logo + 名称 + 认证徽标）。点击进品牌详情（C 档）→ 本批 toast。
   - **品牌故事 / 认证区**：图文段落 + 认证图标行。纯展示。
   - 无品牌数据：整区隐藏。
10. **热门推荐**：`section-header`「热门推荐」+「查看全部」；2 列网格 `product-card`。数据 `GET /products`（取 isHot/isNew）。
11. **海报位 / 弹窗广告**【A 档】：
    - **整页海报卡**：内容流中部/底部的整宽图卡（`GET /page-content/home` 的 posters）。点击按跳转类型处理；活动类 → toast。
    - **弹窗广告**：`onShow` 首次进入弹出居中卡 + 右上关闭按钮（`GET /popups?scene=home`）。
      - 关闭后本地记录（`wx.setStorageSync` 当日不再弹）。点击图按跳转类型处理；活动/资金类 → toast。
    - 无数据：不弹、不渲染。
12. **底部品牌信息**：金色分割线 + 「WENLAN BEAUTY · 问兰」标语。

### 数据与生命周期
- `onLoad`：并行请求 banners、categories、products、coupons/home、points/summary、page-content/home；先显示 `skeleton`。
- `onShow`：刷新签到态、积分；触发当日弹窗判断。
- `onPullDownRefresh`：重新拉取全部，完成 `wx.stopPullDownRefresh`。
- 倒计时 `onShow` 启动、`onHide` 清除，防内存泄漏。

### 状态
- 加载：骨架屏（banner 块 + 2 列卡片骨架）。
- 错误：toast +「点击重试」。各运营区独立失败时各自隐藏，不阻塞主流程。
- 空：products 为空时热门区显示 `empty-state`。

# 页面 2 · 分类 / 商品列表 `pages/category/category`

左侧分类竖向导航 + 右侧内容区**锚点联动滚动**（非简单筛选），并支持搜索。

### 布局
```
┌──────────────────────────┐
│ 搜索栏（含返回，可聚焦）        │  ← focus=1 时自动聚焦
├──────┬───────────────────┤
│ 分类 │  排序栏（综合/销量/价格）   │
│ 侧栏 ├───────────────────┤
│(左) │  内容区：多分区锚点滚动      │
│      │  · 组合商品专区             │
│      │  · 普通商品分区(按分类)      │
│      │  上拉加载更多              │
└──────┴───────────────────┘
        ▲ 底部浮动「购物袋」→ 点击弹出购物袋面板
```

### 模块
1. **搜索栏**：顶部，输入跳 `GET /products/search`。`focus=1` 参数时自动 `focus`。
2. **左侧分类栏**【A 档·锚点联动】：宽 180rpx，竖排 `GET /categories`。
   - 选中项左侧金色竖条 + 白底 + 文字加粗；未选 `--color-surface-warm`。
   - **联动滚动**：点击分类 → 右侧 `scroll-view` 用 `scroll-into-view` 滚动到对应分区锚点；右侧滚动时反向高亮当前分区（监听 `scroll` + 各分区 `offsetTop` 计算当前 active）。
3. **排序栏**：综合 / 销量 / 价格（价格点击切换升降序箭头）。激活态金色。
4. **组合商品专区**【A 档】：内容区顶部独立分区（若该分类下有组合）。
   - `bundle-card`：组合主图 + 「套餐」金色标签 + 套餐价 `price-text` + 划线原单品合计 + 「N 件组合」。
   - 点击进组合详情页（C 档承接完整下单）→ 本批 toast；或进普通详情展示组合内容（按后端能力，缺则 toast）。
5. **普通商品分区**：按分类分段，每段顶部小标题（作为锚点）+ `product-card` list 横卡。数据 `GET /products?category=&sort=&page=`。
6. **分页**：`onReachBottom` 加载下一页，底部「加载中 / 没有更多了」。
7. **底部浮动购物袋 + 购物袋弹层**【A 档】：
   - 右下角浮动按钮：购物袋图标 + 件数角标（`GET /cart` 件数）。
   - 点击从底部弹出 `bag-sheet` 半屏面板：
     - 顶部：「购物袋」+ 全选 + 「清空」。
     - 列表：商品图 + 名称/规格 + `price-text` + `quantity-stepper`（改数 `PUT /cart/:id`，删除 `DELETE /cart/:id`）。
     - 底部：合计（前端累加选中）+「去结算」→ **资金红线** → `toast 功能开发中`。
   - 弹层与购物车页共用购物车数据，操作后同步 tabBar 角标。

### 交互
- 切换分类：锚点滚动到对应分区（不重置整页）；筛选/排序变化才重置 page=1。
- 加购：点 list 卡加购按钮 → 打开 `sku-sheet` → confirm 调 `POST /cart`，成功后更新购物车 tabBar 角标与购物袋件数。

### 状态
- 加载：右侧列表骨架（list 类型）。
- 空：搜索/筛选无结果 → `empty-state`「没有找到相关商品」。
- 错误：toast + 重试。

# 页面 3 · 商品详情 `pages/product/detail`

进入参数：`?id=商品ID`，可选 `?mode=flash|points|group|bargain`（来自首页/活动入口）。
数据主源 `GET /products/:id`，评价 `GET /products/:id/reviews`，活动态 `GET /products/:id/activity`（若有）。

### 模块顺序
1. **自定义导航栏** `nav-bar`：沉浸式，`onPageScroll` 控制 `bgOpacity`。右侧「分享」图标 → 打开分享面板（见模块 11）。
2. **主图区**：`swiper` 商品图集，1:1，底 `--color-surface-warm`。右下角页码 `1/5`。
   - 活动态（B 档）：主图左上角叠活动角标（限时/积分兑换/拼团/砍价）。
3. **价格区**（白卡）【B 档·多形态】：
   - **标准态**：大号 `price-text`（lg）现价 + 划线原价 + 折扣 `tag-label`。
   - **限时专享态**（`mode=flash`）：红金活动价 + 划线日常价 +「限时」标签 + **活动倒计时** + **活动库存条「仅剩 X 件 / 已抢 Y%」** +「不可叠加优惠券」说明。售罄显示「已抢完」置灰。
   - **积分兑换态**（`mode=points`）：价格区显示「N 积分」或「N 积分 + ¥M」，标注当前积分是否足够（`GET /user/points/summary`）。
   - 右侧收藏 ♥（`GET /user/favorites/status`，点 `POST/DELETE /user/favorites`，收藏非资金可实现）。
4. **多购买模式切换卡**【B 档·完整设计】：价格区与规格区之间，仅当商品支持多模式时显示。
   - 横排可切的模式 tab：`标准购买 / 限时专享 / 积分兑换 / 拼团 / 砍价`（按 `activity` 返回的可用模式动态渲染）。
   - 选中模式驱动价格区、按钮区文案与状态联动变化（纯前端切换，不调资金接口）。
   - 各模式按钮文案：标准「立即购买」；限时「立即抢购」；积分「积分兑换」；拼团「¥X 开团 / ¥Y 单买」；砍价「发起砍价」。
5. **拼团 / 砍价承接区**【B 档·完整设计】：当模式为拼团/砍价时，规格区上方插入活动卡。
   - **拼团卡**：拼团价 +「N 人成团」+ 正在进行的团列表（头像 + 还差几人 +「去参团」倒计时）+「查看我的拼团」入口。
   - **砍价卡**：砍价进度条（当前价 / 最低价）+「帮我砍」「我要砍价」+「砍价记录」入口。
   - 所有「开团付款 / 参团付款 / 确认砍价购买」最终动作 → **资金红线** → toast。展示、进度、分享拉人等非资金交互可做。
6. **积分奖励 / 可用券条**【B 档 UI】：价格区下方。
   - 「下单预计得 N 积分」（来自 product 或 activity 字段）。
   - 可领/可用优惠券小票（横滑 `coupon-card` 迷你态），「领取」→ **资金红线（写账户）** → toast；仅展示券面与门槛。
7. **标题区**：商品名（`--fs-title`）+ 副标题 + 标签组（`tag-label`）+ 销量/评分。
8. **规格摘要行**：显示「已选 默认规格」，点击打开 `sku-sheet`。右箭头。
9. **服务承诺行**：正品保障 / 七天无理由 / 顺丰发货 等图标文案（静态或来自 config）。
10. **商品详情**：`description` 文本 + 详情图（`rich-text` 或图片流）。规格参数表（`product.specs`）。
11. **用户评价**：`section-header`「用户评价」+ 评分；列 2~3 条 `GET /products/:id/reviews`，更多本批可 toast 或留空。
12. **分享面板**【A/B 档·完整设计】：点导航栏分享图标后从底部弹出 `share-sheet`。
    - 三入口：**分享给好友**（`open-type="share"` 的 button，走 `onShareAppMessage`）、**分享到朋友圈**（`onShareTimeline`，并提示朋友圈需右上角菜单）、**生成海报**。
    - **海报带券选择区**：可勾选「附带优惠券」（仅展示券选择 UI）；生成海报 = 画 `canvas`（商品图 + 名称 + 价格 + 小程序码 + 可选券信息）→ `wx.saveImageToPhotosAlbum`。
    - 小程序码/海报数据接口若涉及券绑定写账户 → 该部分 toast，海报本身（不带券）可生成。
13. **底部操作栏**（fixed，安全区）：
    - 左：客服图标（toast）、收藏、购物车图标（跳购物车）。
    - 右：按当前购买模式渲染主/次按钮（见模块 4 文案）。
    - 「加入购物车」→ `sku-sheet` mode=cart → `POST /cart`（可实现）。
    - 「立即购买 / 抢购 / 积分兑换 / 开团 / 砍价购买」→ **资金红线** → `toast 功能开发中`。

### 状态
- 加载：detail 骨架（大图块 + 文字条 + 底栏）。
- 活动失效：活动态降级为标准态并提示「活动已结束」。
- 错误/不存在：整页 `empty-state`「商品不存在或已下架」+ 返回按钮。

# 页面 4 · 购物车 `pages/cart/cart`

数据源 `GET /cart`。本批实现「展示 + 选择 + 改数量 + 删除 + 校验态」，**结算属资金红线** → toast。

### 模块
1. **导航标题**：「购物车」+ 右上「管理」（进入编辑/批量删除态）。
2. **空购物车态**【A 档·完整设计】：无商品时
   - `empty-state` 插画 + 文案「购物车还是空的」+「去逛逛」按钮（跳首页）。
   - 下方**推荐商品横滑/网格区**：`section-header`「为你推荐」+ `product-card`（数据 `GET /products` 热门）。点击进详情。
3. **商品列表**：每项 = 左多选框 + 商品图(160rpx) + 名称/规格 + `price-text` + `quantity-stepper`。
   - 改数量：`PUT /cart/:id`。
   - 左滑或编辑态删除：`DELETE /cart/:id`，确认弹窗。
   - 单选/全选用本地 +（可选）`POST /cart/check` 同步选中态。
4. **结算前校验失败态**【A 档·完整设计】：依据 `GET /cart` 返回的每项状态渲染。
   - **失效商品**（下架/售罄）：整项置灰 + 「失效」标签 + 不可勾选；顶部聚合「失效商品 N 件 · 清空」按钮（`DELETE` 批量）。
   - **库存不足**：红色提示「仅剩 X 件」，数量超库存时步进器封顶 + 文案提示。
   - **限购**：提示「每人限购 X 件」，超限禁止增加。
   - 选中项里含异常时，底部「去结算」**禁用态**（置灰）并提示「请先处理失效/超限商品」。
5. **底部结算栏**（fixed，安全区）：
   - 左：全选框 + 「合计 ¥xxx」（仅累加可结算的选中项，前端计算展示）。
   - 右：**去结算（N）** → **资金红线** → `toast 功能开发中`（不跳转、不调下单接口）。校验失败时本就禁用。
   - 编辑态时右侧按钮变「删除选中」。

### 交互与状态
- 进入与 `onShow` 都刷新购物车（从详情加购返回需更新）。
- 数量变更后实时更新合计与 tabBar 角标。
- 加载：list 骨架。错误：toast。

# 页面 5 · 我的 `pages/user/user`

数据源：`GET /user/profile`、`GET /user/account-snapshot`、`GET /user/stats`、`GET /user/roles`（角色/门店身份）。
**严格按角色/场景分区**（沿用 Web 版重构后的信息架构）。

### 模块顺序
1. **用户信息卡**（深棕渐变卡 `--color-primary`）：
   - 头像（无则金色圆底「问」字占位）+ 昵称（`GET /user/profile`）+ 会员等级徽标（`GET /user/member-tier-meta`）。
   - **身份徽标区**【A 档】：根据 `GET /user/roles` 叠加角色徽标（普通会员 / 店长 / 分销商 / 门店归属）。有门店则显示门店名小行。
   - 未登录态：显示「点击登录」→ `wx.login` → `POST /login`。
   - 资产四格：积分 / 优惠券 / 收藏 / 余额（`account-snapshot`）。**余额/钱包点击属资金红线 → toast**；积分、优惠券、收藏可跳轻页面或本批 toast。
2. **我的订单**（白卡）：标题 + 「全部订单」。状态宫格（待付款/待发货/待收货/待评价/退款售后）带角标（`GET /orders/counts`）。
   - **订单全属 C 档** → 整块保留 UI、显示角标数字，点击任意项 `toast 功能开发中`。
3. **购物袋摘要卡**【A 档】：订单卡下方。
   - 横滑已选商品缩略图 + 件数 + 合计金额 +「去结算」。数据 `GET /cart`。
   - 「去结算」→ **资金红线** → toast。缩略图点击进详情可实现。无购物车数据则隐藏。
4. **浏览足迹**（横滑）：本批可用收藏 `GET /user/favorites` 或本地足迹；无数据隐藏整块。
5. **买家工具**（白卡，4 宫格）：地址管理 / 优惠券 / 我的收藏 / 客服中心。
   - 地址管理可实现只读列表（`GET /addresses`）；增删改属 C 档。其余跳轻页面或 toast。
6. **角色功能区**【A 档·按权限显示】：依据 `GET /user/roles` 条件渲染，**入口在 5 页内、目标页属 C 档**。
   - 有分销/店长身份才显示该卡：钱包 / 推广素材 / 店长工作台 / 自提核销 / 团队中心。
   - 所有入口点击 → `toast 功能开发中`，**不调用** distribution/wallet/agent/核销 任何接口。
   - 无相关身份则整卡隐藏（普通用户看不到分销区）。
7. **业务密码入口**【A 档】：账号安全/设置区的列表行。
   - 显示「业务密码」+ 状态（未设置：金色「去设置」；已设置：「修改」）。
   - 设置/修改流程页属 C 档 → 点击 toast；仅展示入口与状态文案（状态来自 `GET /user/security` 若有，缺则显示「去设置」）。
8. **设置**（独立列表行）：跳设置页或 toast。

### 状态
- 未登录：信息卡显示登录引导，下方功能区正常展示但点击需登录的项先引导登录；角色区隐藏。
- 加载：信息卡 + 卡片骨架。
- 错误：toast，关键信息（昵称/资产）失败用占位「--」。
