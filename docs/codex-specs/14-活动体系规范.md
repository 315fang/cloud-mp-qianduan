# 问兰小程序 · 活动体系规范（C 档 · 四期）

> 真相源：`miniprogram/utils/requestRoutes.js`。**资金红线**：开团/参团付款、确认砍价购买、限时抢购下单均为下单付款动作，止于接口边界，未接通前 `toast 功能开发中`。活动浏览、倒计时、分享拉人可完整实现。

## 页面清单

| 页面 | 路径建议 | 说明 |
| --- | --- | --- |
| 拼团列表 | `pages/activity/group/list` | 拼团商品 + 我的拼团 |
| 拼团详情 | `pages/activity/group/detail` | 开团/参团承接 |
| 砍价列表 | `pages/activity/slash/list` | 砍价商品 + 我的砍价 |
| 砍价详情 | `pages/activity/slash/detail` | 砍价进度 + 帮砍 |
| 种草动态 | `pages/content/feed` | 品牌/用户内容流 |

> 限时专场/随心选可直接复用首页 `activity-card`（见 03 文档 #16），无独立列表则并入首页活动专区。

## 通用配色
- 活动促销价用**红 `#E57373`**（区别于常规金色价），划线原价 `#B8A898`。
- 活动说明横幅用深棕 `#1A1208` 底 + 金色高亮。

---

## 1. 拼团 `pages/activity/group/*`

### 列表页
1. **顶栏** +「拼团」。
2. **说明横幅**（深棕渐变）：「拼团专享价」+ 「邀请好友一起拼，享受更低价格」。
3. **Tab**（段控）：拼团商品 / 我的拼团。
4. **拼团商品卡**：
   - 上半：图 + 名称 + 拼团价（红）+ 划线原价 + 「N人团」标签 + 「需N人成团」+ 「Nh有效」。
   - 下半（分隔线）：成团进度圆点（已加入金色实心 + 待加入空心）+ 「还差N人」+ 红色「去拼团」按钮。
5. **我的拼团**：进行中的团卡（进度 + 倒计时 + 邀请按钮）；空态「还没有参与拼团」。

### 详情页
- 商品主图 + 拼团价 + 倒计时。
- 进行中团列表：发起人头像 + 「还差几人」+ 倒计时 + 「去参团」。
- 「我也要开团」「邀请好友参团」。
- **开团/参团付款属红线** → 按钮 toast；分享拉人用 `open-type="share"` 可做。

### 接口
- `GET /activity/group/list`、`GET /activity/group/:id`、`GET /activity/group/mine`。
- `POST /activity/group/open`、`/join`（**红线**）。

---

## 2. 砍价 `pages/activity/slash/*`

### 列表页
1. **顶栏** +「砍一刀」。
2. **说明卡**（深棕）：「全员可参与」标签 + 「发起砍价，好友帮砍」+ Scissors 图标。
3. **Tab**：砍价商品 / 我的砍价。
4. **砍价商品卡**：图 + 名称 + 「原价→底价」对比（底价红）+ 「最多N人帮砍」+ 「Nh有效」+ 「已有N+人参与」+ 红色「发起砍价」。
5. **我的砍价**：当前价 + 底价 + 「进行中」标签 + 帮砍进度条（红）+ 截止时间 + 「邀请好友帮我砍」深棕按钮；空态「还没有砍价记录」。

### 详情页
- 当前价大字 + 底价 + 进度条（已砍金额/差额）。
- 帮砍记录列表（头像 + 砍掉金额 + 时间）。
- 「邀请好友帮砍」（分享）+ 「以当前价购买」。
- **发起砍价/确认购买属红线** → toast；帮砍分享可做。

### 接口
- `GET /activity/slash/list`、`GET /activity/slash/:id`、`GET /activity/slash/mine`。
- `POST /activity/slash/launch`、`/help`、`/buy`（**红线**）。

---

## 3. 种草动态 `pages/content/feed`

> 品牌/用户内容流，纯展示与轻互动，非资金。

1. **顶栏** +「种草动态」。
2. **动态卡**（列表）：
   - 作者头像 + 昵称 + 时间 + 「关注」按钮。
   - 正文（leading-relaxed）。
   - 图片网格（1 图 4:3，2 图 2 列，≥3 图 3 列）。
   - 关联商品条（`#F5EFE8` 底）：小图 + 商品名 + 「查看 ›」跳详情。
   - 互动栏：点赞（Heart，选中红色填充）/ 评论 / 分享 / 右侧收藏（Bookmark，选中金色）。
3. **正文 emoji**：用户内容中的 emoji 属真实文案可保留；但**功能图标禁用 emoji**。

### 接口
- `GET /content/feed?page=`、`POST /content/:id/like`、`POST /content/:id/favorite`、`POST /content/author/:id/follow`（均非资金，可接通）。

## 实现提示
- 倒计时、进度条、成团圆点均前端渲染；活动价与库存以 `GET /products/:id/activity` 为准。
- 分享统一 `open-type="share"`；海报 canvas 生成。
- 活动卡复用 03 文档 `activity-card`；商品卡复用 `product-card`。
- 严守红线：开团/参团/砍价购买/抢购下单一律 toast，下单由后端。
