# 问兰小程序 · 积分体系规范（C 档 · 三期）

> 真相源：`miniprogram/utils/requestRoutes.js`。**资金红线**：积分兑换商品/券、抽奖扣积分等涉及积分账户写操作，未接通前 `toast 功能开发中`，仅展示。签到/任务领分若后端确认不耦合资金账户可接通。

## 页面清单

| 页面 | 路径建议 | 说明 |
| --- | --- | --- |
| 积分中心 | `pages/points/center` | 余额、任务、流水、等级特权 |
| 积分抽奖 | `pages/points/lottery` | 九宫格转盘 |

---

## 1. 积分中心 `pages/points/center`

### 导航
返回 + 居中「积分中心」+ 右上「去抽奖」金色文字链接。

### 主卡片（深棕 `#1A1208` 底）
- 顶行：`Lv.N 等级名` 金色胶囊 + 右侧「累计 N 积分」。
- 大字可用积分（4xl 粗体）+「可用积分」副label。
- **升级进度条**：「距离 X 还差 N 积分」+ 当前/阈值 + 金色进度条。
- 底部 3 宫格快捷：积分兑换 / 抽奖中心 / 等级特权（图标 + label）。

### Tab（段控，`--color-cream` 底 + 白色滑块）
`赚积分 / 积分流水 / 等级特权`

**赚积分**：任务卡列表
- 左圆标（未完成金色 Zap / 已完成灰对勾）+ 标题 + 描述 + `+N` 分 + 「去完成/已完成」按钮。
- 任务示例：每日签到、完成订单、评价商品、邀请好友、分享商品、完善资料。

**积分流水**：收支记录
- 左圆标（+绿 / -红 Star）+ 标题 + 日期 + 右侧带符号分值（绿/红）。

**等级特权**：等级卡列表
- 卡头按等级配色（Lv1 灰 / Lv2 金 / Lv3 深棕底金字）+ Crown + 等级名 +「当前等级/待解锁」标记。
- 卡体：权益列表（对勾 + 文字），已达等级金色，未达灰色。
- 当前等级卡金色 2rpx 描边。

### 接口
- `GET /user/points/summary`（余额/等级/进度）
- `GET /user/points/tasks`、`GET /user/points/logs`
- 任务领分 `POST /user/points/task/:id/claim`（**确认非资金后接通**，否则 toast）

## 2. 积分抽奖 `pages/points/lottery`

整页深棕 `#1A1208` 底，营造抽奖氛围。

### 区块
1. **导航**：返回 + 居中「积分抽奖」。
2. **积分头部**：积分胶囊（Star + 数值）+「每次消耗 N 积分」。
3. **九宫格转盘**（`#2A1E0E` 底卡）：
   - 3×3 网格，**中心格为抽奖按钮**（Gift + 「立即抽奖/抽奖中」），外圈 8 格为奖品。
   - 奖品格：图标 + 名称；抽奖时高亮格在外圈按顺序流转（先匀速后减速停在结果格）。
   - 积分不足或抽奖中禁用中心按钮。
   - **奖品图标禁用 emoji**（Web 版用了 ✨🎫 仅占位），小程序须替换为正式图标或图片素材。
4. **获奖提示**（`#FFF7E6` 卡）：Trophy + 「恭喜获得 X」+ 「已发放至账户」。
5. **奖品说明**：4 列网格展示可获奖品（排除「谢谢参与」）。
6. **中奖动态**：滚动记录列表（用户脱敏名 + 奖品 + 时间）。

### 抽奖逻辑与红线
- 转盘动画为纯前端表现。
- **真正的抽奖结果与扣分必须由后端裁决**（防作弊），前端动画停在后端返回的中奖索引。
- 接通前：`toast 功能开发中`；接通后 `POST /lottery/draw` 返回结果再播放停格动画。

### 接口
- `GET /lottery/config`（奖池）
- `POST /lottery/draw`（**资金红线，扣积分由后端**）
- `GET /lottery/records`（中奖动态）
