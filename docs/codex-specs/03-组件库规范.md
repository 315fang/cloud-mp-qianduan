# 问兰小程序 · 组件库规范

> 配套 `01-设计系统规范.md`、`02-颜色&排版.md`。
> 本文定义首批 5 个页面所需的可复用组件。所有组件为微信原生**自定义组件**（`Component`），开启 `styleIsolation: 'apply-shared'` 以复用 page 令牌。
> 组件 properties 命名小驼峰；对外事件用 `triggerEvent`。

## 组件清单

| 组件 | 目录 | 用于页面 |
| --- | --- | --- |
| 自定义导航栏 `nav-bar` | `components/nav-bar` | 详情、分类（可选） |
| 区块标题 `section-header` | `components/section-header` | 首页、详情、我的 |
| 商品卡片 `product-card` | `components/product-card` | 首页、分类 |
| 价格文本 `price-text` | `components/price-text` | 全部 |
| 标签 `tag-label` | `components/tag-label` | 首页、分类、详情 |
| 数量步进器 `quantity-stepper` | `components/quantity-stepper` | 购物车、详情规格弹层 |
| 规格选择弹层 `sku-sheet` | `components/sku-sheet` | 首页、分类、详情 |
| 空状态 `empty-state` | `components/empty-state` | 全部列表页 |
| 骨架屏 `skeleton` | `components/skeleton` | 全部 |

## 1. `section-header` 区块标题

区块顶部「图标 + 标题 + 右侧更多」。

**properties**
| 名 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | String | '' | 主标题 |
| `icon` | String | '' | 左侧图标路径（可空） |
| `moreText` | String | '' | 右侧文字，如「查看全部」，空则不显示 |

**events**：`bindtap`（点击右侧更多触发 `more`）

**结构**
```html
<view class="sh">
  <view class="sh__left">
    <image wx:if="{{icon}}" class="sh__icon" src="{{icon}}" />
    <text class="sh__title">{{title}}</text>
  </view>
  <view wx:if="{{moreText}}" class="sh__more" bindtap="onMore" hover-class="opacity-60">
    <text>{{moreText}}</text>
    <image class="sh__arrow" src="/assets/icons/chevron-right.svg" />
  </view>
</view>
```

**样式要点**
- `.sh`：flex，space-between，align-center，margin-bottom `24rpx`。
- `.sh__title`：`--fs-heading`（32rpx），700，`--color-primary`。
- `.sh__icon`：28rpx 见方，金色。
- `.sh__more`：`--fs-caption`（24rpx），`--color-gold`。

## 2. `product-card` 商品卡片

两种布局，对应首页/分类。

**properties**
| 名 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `product` | Object | {} | 商品对象（字段见下） |
| `layout` | String | 'grid' | `grid`（竖卡）/ `list`（横卡） |

`product` 字段（与后端 `GET /products` 返回映射，详见接口文档）：
```
{ id, name, subtitle, price, originalPrice, image,
  rating, tags:[], isNew, isHot, stock }
```

**events**
- `bindtap` → 触发 `tapcard`，detail `{ id }`（页面负责 `wx.navigateTo` 到详情）
- 加购按钮 → 触发 `addcart`，detail `{ product }`（页面负责打开 `sku-sheet`）

**grid 布局结构**
```html
<view class="pc pc--grid" bindtap="onTap" hover-class="pc--active">
  <view class="pc__media">
    <image class="pc__img" src="{{product.image}}" mode="aspectFit" />
    <tag-label wx:if="{{product.isNew}}" type="new" text="NEW" class="pc__badge" />
    <tag-label wx:elif="{{product.isHot}}" type="hot" text="HOT" class="pc__badge" />
    <view class="pc__cart" catchtap="onAddCart">
      <image src="/assets/icons/bag.svg" />
    </view>
  </view>
  <view class="pc__info">
    <text class="pc__name ellipsis-1">{{product.name}}</text>
    <text class="pc__sub ellipsis-1">{{product.subtitle}}</text>
    <view class="pc__bottom">
      <price-text price="{{product.price}}" origin="{{product.originalPrice}}" />
      <view class="pc__rating">
        <image src="/assets/icons/star.svg" /><text>{{product.rating}}</text>
      </view>
    </view>
  </view>
</view>
```

**样式要点**
- `.pc--grid`：背景白，圆角 `--radius`（24rpx），`--shadow-card`，overflow hidden。
- `.pc__media`：宽高比 1:1，底色 `--color-surface-warm`，图 `aspectFit` 内边距 `32rpx`。
- `.pc__badge`：绝对定位左上 `16rpx`。
- `.pc__cart`：绝对定位右下，48rpx 圆形，底 `--color-primary`，白图标，`:active` 缩放 0.95。
- `.pc__name`：`--fs-body-lg`（30rpx）600。
- `.pc__sub`：`--fs-caption` `--color-muted`。
- **list 布局**：横向 flex，左图 200rpx 见方，右侧上下分布名称/标签/价格，详情见首批页面文档分类页。

> 加购按钮务必用 `catchtap` 阻止冒泡，避免触发整卡跳转。

## 3. `price-text` 价格文本

统一价格展示（见排版文档第 6 节）。

**properties**
| 名 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `price` | Number/String | 0 | 现价 |
| `origin` | Number/String | 0 | 原价，>price 时显示划线 |
| `size` | String | 'md' | `sm`/`md`/`lg`，控制数字字号 |

**结构**
```html
<view class="pt pt--{{size}}">
  <text class="pt__symbol">¥</text>
  <text class="pt__num">{{price}}</text>
  <text wx:if="{{origin && origin > price}}" class="pt__origin">¥{{origin}}</text>
</view>
```
- `.pt__num`：700，`--color-primary`，`tabular-nums`。`sm`=28 / `md`=32 / `lg`=44 rpx。
- `.pt__symbol`：小一档。
- `.pt__origin`：`--color-muted`，line-through，`--fs-caption`，margin-left `8rpx`。

## 4. `tag-label` 标签 / 徽标

**properties**
| 名 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `text` | String | '' | 文字 |
| `type` | String | 'default' | `default`/`hot`/`new`/`gold`/`soft` |

**样式映射**
| type | 底色 | 文字色 |
| --- | --- | --- |
| `new` | `--color-primary` | 白 |
| `hot` | `--color-gold` | 白 |
| `gold` | `--color-gold` | 白 |
| `soft` | `--color-gold-pale` | `--color-gold` |
| `default` | `--color-surface-warm` | `--color-primary-light` |

- 统一胶囊 `--radius-full`，`--fs-mini`（20rpx），padding `4rpx 12rpx`，`letter-spacing: 2rpx`。

## 5. `quantity-stepper` 数量步进器

**properties**：`value`(Number,1)、`min`(Number,1)、`max`(Number,99)
**events**：`bindchange` → `{ value }`

**结构**：`[ − ]  value  [ + ]`
- 减号按钮：圆形 48rpx，描边 `--color-border`，文字 `--color-primary`；到 min 时置灰禁用。
- 加号按钮：圆形 48rpx，实底 `--color-primary`，白色 `+`；到 max 禁用。
- 中间数字：`--fs-body-lg`，居中宽 40rpx。

---

## 6. `sku-sheet` 规格选择弹层

底部弹出，用于「加入购物车 / 立即购买」选规格与数量。

**properties**
| 名 | 类型 | 说明 |
| --- | --- | --- |
| `show` | Boolean | 控制显隐 |
| `product` | Object | 商品对象（含 specs/stock/price/image） |
| `mode` | String | `cart`（加购）/ `buy`（立即购买，本批可隐藏或 toast 开发中） |

**events**：`bindclose`、`bindconfirm`（detail `{ specValue, qty }`）

**结构要点**
- 遮罩 `rgba(0,0,0,0.4)`，点击关闭。
- 弹层底白，顶部圆角 `--radius-lg`（40rpx），从底部滑入（transform translateY 动画 0.25s）。
- 顶部：商品小图(160rpx) + 价格 + 名称 + 关闭 X。
- 规格区：`product.specs` 中可选项渲染为胶囊按钮组，选中态实底 `--color-primary` 白字，未选描边。
- 数量区：复用 `quantity-stepper` + 库存文案。
- 底部主按钮：满宽胶囊，底 `--color-primary` 白字「加入购物车」。加购成功态变 `--color-success` + 「已加入」+ 勾。
- 安全区：底部 `padding-bottom: env(safe-area-inset-bottom)`。

> 本批 `mode='buy'`（立即购买）会进入下单/支付流程，属排除范围：按钮可隐藏，或点击仅 `wx.showToast({title:'功能开发中'})`。

## 7. `empty-state` 空状态

**properties**：`text`(String)、`subText`(String)、`buttonText`(String)、`icon`(String)
**events**：`bindaction`（按钮点击）

- 垂直居中，图标 200rpx（淡灰），主文案 `--fs-body` `--color-muted`，副文案 `--fs-caption`。
- 按钮（可选）：胶囊描边 `--color-gold`，文字金色。
- 场景文案：购物车空→「购物车还是空的」+「去逛逛」；搜索无结果→「没有找到相关商品」；收藏空→「还没有收藏」。

---

## 8. `skeleton` 骨架屏

**properties**：`type`(String：`product-grid`/`list`/`detail`)、`count`(Number,4)

- 灰块 `--color-surface-warm`，圆角 `--radius-sm`，1.2s 呼吸/微光动画。
- `product-grid`：渲染 N 个卡片骨架（图块 + 两行文字条）。
- 数据加载期间显示，成功后隐藏。

---

## 9. `nav-bar` 自定义导航栏（详情页用）

商品详情页使用沉浸式/自定义导航（滚动时背景渐显）。

**properties**：`title`(String)、`bgOpacity`(Number,0~1，随滚动变化)、`showBack`(Boolean,true)
**events**：`bindback`

- 高度 = 状态栏高 + 88rpx。
- 返回按钮：圆形半透明底 `rgba(255,255,255,0.7)`，深棕箭头。
- `bgOpacity` 由页面 `onPageScroll` 计算后传入：0 时透明（图片沉浸），滚动超过一屏渐变到白底 + 显示标题。
- 标题 `--fs-body-lg` 600，居中。

---

## 10. 图标资源约定

- 图标放 `assets/icons/`，统一线性风格，`strokeWidth ≈ 1.5`，建议 SVG。
- 常用：`home` `category` `cart` `user` `search` `bell` `bag`(购物袋) `star` `chevron-right` `chevron-left` `plus` `minus` `check` `close` `location` `heart`。
- 未激活 `--color-muted`，激活 `--color-gold`。
- **禁止用 emoji 代替图标**（`data.ts` 中分类的 ✦◈◇ 仅 Web 占位，小程序须替换为正式图标或保留为装饰文字，不作为功能图标）。
