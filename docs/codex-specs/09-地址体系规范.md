# 问兰小程序 · 地址体系规范（C 档 · 二期）

> 真相源：`miniprogram/utils/requestRoutes.js`。地址 CRUD **非资金操作**，可正常接通后端。

## 页面清单

| 页面 | 路径建议 | 说明 |
| --- | --- | --- |
| 地址列表 | `pages/address/list` | 增删改 + 设默认 |
| 地址编辑 | `pages/address/edit` | 新增/编辑共用，带 id 区分 |

---

## 1. 地址列表 `pages/address/list`

- 顶栏：返回 + 居中「收货地址」。
- 地址卡（白底圆角，块间距 24rpx）：
  - 圆形 MapPin 图标 + 姓名（粗）+ 手机（muted）+「默认」金色小标签。
  - 多行详细地址（muted）。
  - 分隔线下操作行：`设为默认`（非默认才显示，左）/ `编辑`（右）/ `删除`（红色）。
- **底部固定栏**：深棕胶囊「+ 新增收货地址」，按钮跳 `edit`。
- 选择模式：从结算页进入时，点击卡片直接回填并返回（`?select=1`）。
- 接口：
  - `GET /addresses` 列表
  - `PUT /addresses/:id/default` 设默认
  - `DELETE /addresses/:id` 删除（二次确认 `wx.showModal`）

---

## 2. 地址编辑 `pages/address/edit`

- 顶栏标题：新增显示「新增地址」，编辑显示「编辑地址」。
- **表单卡**（白底，分隔线分行）：
  | 字段 | 控件 | 校验 |
  | --- | --- | --- |
  | 收货人 | 文本输入 | 必填 |
  | 手机号码 | tel 输入 | 必填，11 位 |
  | 所在地区 | **`picker mode="region"`**（小程序原生省市区选择器，替代 Web 的文本框） | 必填 |
  | 详细地址 | textarea 2 行 | 必填 |
- **设为默认**：独立卡片 + 金色开关（toggle）。
- **导入微信地址**（小程序增强）：顶部提供「`<button open-type="chooseAddress">` 导入微信地址」一键填充。
- **底部固定栏**：保存按钮，表单不完整时置灰禁用（`#F0E8DC` 底 + `#B8A898` 字），完整时深棕高亮。
- 接口：
  - 新增 `POST /addresses`
  - 编辑 `PUT /addresses/:id`
  - 保存成功 toast + 返回列表。

---

## 实现提示
- 地区选择必须用小程序原生 `picker region`，不要照搬 Web 的纯文本输入。
- 提供 `chooseAddress` 微信地址导入，提升填写效率。
- 列表/编辑可抽 `address-card` 组件。
