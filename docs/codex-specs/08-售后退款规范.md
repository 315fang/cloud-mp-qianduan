# 问兰小程序 · 售后/退款规范（C 档 · 三期）

> 真相源：`miniprogram/utils/requestRoutes.js`。**资金红线**：提交退款申请、确认退款均涉及资金流，未接通前 `toast 功能开发中`，仅完成表单与展示。

## 页面清单

| 页面 | 路径建议 | 说明 |
| --- | --- | --- |
| 售后列表 | `pages/aftersale/list` | 退款单状态列表 |
| 退款申请 | `pages/aftersale/apply` | 表单（从订单详情进入，带 orderId） |
| 退款详情 | `pages/aftersale/detail` | 进度时间线 |

---

## 1. 售后列表 `pages/aftersale/list`

- 顶栏：返回 + 居中「退款/售后」。
- 列表项卡（点击进详情）：
  - 卡头：退款单号（muted）+ 状态胶囊。
  - 主体：商品图 112rpx + 名称（line-clamp-2）+ 日期 + 金色退款金额。
- 状态配色：
  | status | 文字/底色 |
  | --- | --- |
  | processing 处理中 | 金 `#B8973A` / `#FFF7E6` |
  | approved 已退款 | 绿 `#388E3C` / `#E8F5E9` |
  | rejected 已拒绝 | 红 `#D32F2F` / `#FFEBEE` |
- 空态：「暂无售后记录」。
- 接口：`GET /aftersale/list`（或 refund 子路由）。

---

## 2. 退款申请 `pages/aftersale/apply`

整页底色 `--color-bg`，白卡分区，块间距 32rpx。

### 表单分区（从上到下）
1. **商品信息卡**：图 + 名称 + 「已支付 ¥X」。
2. **退款类型**（单选卡）：
   - 仅退款（无需退货，直接退款到账户）
   - 退货退款（寄回商品后退款，运费自理）
   - 选中态：金色描边 + `#FFF7E6` 底 + 左侧实心圆点。
3. **退款原因**（2 列网格按钮）：质量问题 / 描述不符 / 尺寸规格不对 / 商品破损 / 未收到货 / 不想要了 / 其他。选中金色描边高亮。
4. **退款说明**（选填）：textarea，最多 200 字，右下字数计数。
5. **上传凭证**（选填）：虚线框「添加图片」按钮，`wx.chooseMedia`，最多 N 张。
6. **退款金额**：`¥` 前缀输入框（金色粗体），右侧「最多 ¥X」上限校验。

### 校验与提交
- 未选原因 → toast「请选择退款原因」。
- 金额不得超过上限。
- **提交属资金红线** → 接通前 toast；接通后 `POST /aftersale/apply`。

### 提交成功页（同页切换或独立态）
- 居中金色对勾圆标 + 「退款申请已提交」+ 「预计 3-5 个工作日内处理，原路退回」+ 「查看退款进度」按钮跳详情。

---

## 3. 退款详情 `pages/aftersale/detail`

### 区块
1. **状态卡**（深棕底）：Clock/对勾图标 + 状态名 + 描述 + 顶部 4 节点进度条（提交申请→商家确认→退款处理→退款到账），完成态金色。
2. **退款信息卡**：退款类型 / 退款原因 / 退款金额（金色高亮）/ 申请时间 / 退款单号。
3. **退款商品卡**：图 + 名称 + 数量。
4. **处理进度时间线**：仅渲染已完成节点，金色实心圆点 + 标签 + 时间。

### 退货退款额外区（当 type=return_refund 且商家已同意）
- **商家寄回地址卡**：收件人 + 电话 + 地址 + 复制按钮。
- **回寄物流录入**：快递公司选择 + 单号输入 + 提交。
- 取消申请按钮（底部，描边）。

### 接口
- `GET /aftersale/:id` 详情。
- `POST /aftersale/:id/ship`（回寄物流）/ `POST /aftersale/:id/cancel`（取消）。

---

## 实现提示
- 进度条、时间线纯前端渲染；退款单号复制用 `wx.setClipboardData`。
- 与订单体系共用 `order-status-tag`、`price-text` 组件。
- 资金红线：提交申请/确认退款在接口接通前 toast。
