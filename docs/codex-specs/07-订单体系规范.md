# 问兰小程序 · 订单体系规范（C 档 · 二期）

> 真相源：接口以 `miniprogram/utils/requestRoutes.js` 为准；下方路径为占位推断，实现前必须核对。
> **资金红线**：付款、确认收货（触发结算）、再次购买下单等最终动作止于接口边界，未接通前 `toast 功能开发中`。

## 页面清单

| 页面 | 小程序路径建议 | 说明 |
| --- | --- | --- |
| 订单列表 | `pages/order/list` | 多状态 Tab |
| 订单详情 | `pages/order/detail` | 进度、地址、商品、价格、订单信息 |
| 物流追踪 | `pages/order/logistics` | 时间线 + 派件员 |

## 1. 订单列表 `pages/order/list`

### 状态 Tab（顶部横滑，吸顶）
`全部 / 待付款 / 待发货 / 待收货 / 已完成 / 退换货`
- 激活态：底部 2rpx 金色下划线 + 金色文字；非激活 `--color-muted`。
- 进入页支持 `?status=` 参数直接定位 Tab（从「我的」宫格跳入）。

### 状态映射与配色
| status | 标签 | 文字色 | 底色 |
| --- | --- | --- | --- |
| pending | 待付款 | 橙 `#F97316` | `#FFF7ED` |
| paid | 待发货 | 蓝 `#3B82F6` | `#EFF6FF` |
| shipped | 待收货 | 金 `--color-gold` | `#F0E6C8` |
| completed | 已完成 | `--color-muted` | `--color-cream` |
| refund | 退款中 | 红 `#F87171` | `#FEF2F2` |

> 后端如有 **待成团 / 自提待核销** 扩展状态，追加 Tab 与映射，配色沿用语义规则。

### 订单卡结构（`order-card`）
1. **卡头**：订单号（左，muted 小字）+ 状态标签（右，胶囊）。
2. **收货地址条**（仅 shipped）：MapPin + 姓名手机 + 地址，底色 `--color-cream`。
3. **商品行**：图 128rpx + 名称（line-clamp-1）+ 副标题 + 价格 + `x{qty}`，多商品纵向堆叠。
4. **状态附加区**（互斥）：
   - pending：橙色条「剩余付款时间 HH:MM:SS」前端倒计时。
   - shipped + expressNo：可展开物流卡（顺丰快递 + 单号 + 折叠时间线）。
   - refund：4 段退款进度条（申请退款→审核中→退款处理→已退款）。
5. **卡底**：日期 + 「共 N 件 · 合计 ¥X」；右下操作按钮组。

### 操作按钮（按状态）
| status | 次按钮（描边） | 主按钮 |
| --- | --- | --- |
| pending | 取消订单 | 立即付款（深棕）**资金红线** |
| paid | 催发货 | — |
| shipped | 查看物流 | 确认收货（深棕）**资金红线** |
| completed | 申请售后 | 再次购买（金）**下单红线** |
| refund | 查看进度 | — |

### 空态
图标圆底 + 「暂无相关订单」+ 副文案 +「去购物」深棕胶囊按钮。

### 接口
- `GET /orders?status=&page=` 列表分页。
- 倒计时由 `createTime + 30min` 前端计算，不轮询。

## 2. 订单详情 `pages/order/detail`

整页底色 `--color-cream`，卡片白底，块间距 24rpx，底部留操作栏高度。

### 区块（从上到下）
1. **状态卡**（深棕 `#1A1208` 底）：大字状态名 + 金色描述文案 + 物流入口胶囊（半透明白底，点击进物流页）。
2. **进度条卡**：5 节点（下单→付款→确认→发货→完成），完成态金色打勾，未完成显示序号 + 灰色连线。
3. **收货地址卡**：圆形 MapPin 图标 + 姓名/手机 + 多行地址。
4. **商品信息卡**：标题「商品信息」+ 商品行（图 + 名 + 规格 spec + 金色价 + 数量），点击进详情。
5. **价格明细卡**：商品小计 / 运费（0 显示「免运费」）/ 优惠券（红色 -¥）/ 分隔线 / 实付款（金色大字）。
6. **订单信息卡**：订单编号（带复制按钮）/ 下单时间 / 支付方式 / 备注。

### 底部操作栏（fixed，白底上边线）
按状态显示：确认收货 / 申请退款（带 RotateCcw 图标，跳 `pages/aftersale/apply?orderId=`）/ 评价晒单 / 立即付款。资金动作止于边界。

### 接口
- `GET /orders/:id` 详情。
- 复制订单号用 `wx.setClipboardData`。

## 3. 物流追踪 `pages/order/logistics`

### 区块
1. **导航栏**：返回 + 居中「物流追踪」+ 右侧刷新按钮。
2. **状态头卡**（深棕底）：Package 图标 + 状态胶囊（按 `statusColors` 映射）+ 预计送达 + 最新一条动态摘要。
   - 状态配色：pending 灰 / in_transit 金 `#FFF7E6` / out_for_delivery 绿 `#E8F5E9` / delivered 金。
3. **运单信息卡**：快递公司 + 运单号（点击复制）+ 收货地址。
4. **派件员卡**（`#FFF7E6` 底）：姓名 + 时段 + 右侧电话圆钮（`makePhoneCall`）。
5. **物流时间线卡**：竖线 + 节点圆点（最新金色实心，其余描边空心）+ 描述 + 时间，最新条加粗。

### 接口
- `GET /orders/:orderNo/logistics`（或物流子路由），失败显示「暂无物流信息」。

## 实现提示
- 倒计时、进度条、时间线均为纯前端渲染。
- 所有金额用 `price-text` 组件；状态标签可抽 `order-status-tag` 组件复用列表与详情。
- 严格遵守资金红线：付款/确认收货/再次购买在接口接通前 toast。
