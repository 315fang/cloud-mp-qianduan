## 全局铁律（贯穿所有文档）

1. **资金红线**：任何触发资金变动的最终动作——支付、领券写账户、扣积分、提现、开团/参团付款、确认砍价购买、核销提交——在接口接通前一律 `wx.showToast` 提示「功能开发中」，**绝不臆造或调用资金接口**。界面、状态、倒计时、分享 UI 可完整实现。
2. **接口真相源优先**：文档接口为推断，以 `requestRoutes.js` 实际定义为准；不存在的接口降级为隐藏或 toast。
3. **原生优先**：地区选择用 `picker region`、地图用 `<map>`、分享用 `open-type="share"`、扫码用 `wx.scanCode`、定位用 `wx.getLocation`——不要照搬 Web 实现。
4. **禁用 emoji 作功能图标**：Web 占位中的 emoji（✨🎫 等）须替换为正式图标；用户文案内的 emoji 可保留。
5. **设计令牌统一**：颜色/间距/圆角严格遵循 02 文档，不引入新色值。
6. **权限可见性**：分销/核销类页面与入口按 `GET /user/roles` 控制显隐。
